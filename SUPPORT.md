# Support

Use GitHub Issues for reproducible connector defects and feature requests. Include the connector version, Power BI Desktop or gateway version, InfluxDB version, selected period, aggregation, field name, and a sanitized error message.

Never attach credentials, authorization headers, full diagnostic traces, private hostnames, or unredacted household entity data.

This connector currently targets InfluxDB 1.x with InfluxQL. InfluxDB 2.x/Flux requests should be tracked as a separate feature.
