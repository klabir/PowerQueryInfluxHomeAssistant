# Privacy

The connector sends InfluxQL requests only to the InfluxDB server configured by the user. It does not contain telemetry, advertising, analytics, or a vendor-operated relay service.

Power BI Desktop, the on-premises data gateway, InfluxDB, and the surrounding network may retain their own diagnostics. Review those products' settings and policies separately. Query previews and refresh diagnostics can contain Home Assistant entity identifiers and measurements; treat them as household data.
